# 7장 초안 — 지식 증류 실험 결과 (D)

> 2026-10-27 기준. 계획한 증류 5개 구성(Mini·Max × 교사 2종, Max+ × Retinexformer)을 모두 끝냈다.

## 슬라이드 제목

**교사를 바꿔도 증류 효과 없음 — 같은 조건에서 일반 학습과 차이 0.01 dB 이내**

## 실험 조건 (한 줄 박스)

LOL-v2-real 학습 620장 / 검증 69장 · random 180×180 crop · batch 40 · 120 epoch · seed 42 · Colab T4
학생은 일반 학습과 **같은 initial.pt**에서 시작, 설정도 같다(증류 항만 추가). 교사는 고정하고 같은 crop을 교사·학생에 넣는다.
손실 = 기존 손실 + 0.3 × SmoothL1(학생 출력, 교사 출력)
교사 2종: **Max+ 일반 학습**(937개, 17.13 dB) / **Retinexformer**(160만 개, 21.99 dB, 우리 학습 데이터로 30000회 학습, 검증 최고인 9000회 가중치)

## 표 (검증 69장 평균 PSNR dB / SSIM)

|---|---|---|---|

## 관찰 (말로 설명할 내용)

1. **교사를 훨씬 강한 Retinexformer(21.99 dB)로 바꿔도 결과가 같았다.** 세 학생 모두 일반 학습과 PSNR 차이가 0.01 dB 이내, 사진별로도 반반이다.
2. **Mini·Max는 교사를 따라가지 못한다.** 증류 손실이 첫 epoch 직후 약 0.053에서 멈춘다. 검증 점수도 4~16 epoch에 최고점을 찍고 그대로다. 학습 신호가 아니라 모델 구조(표현력)의 한계로 보인다(가설).
3. **Max+는 교사를 따라가는데도 검증 점수는 오르지 않았다.** 증류 손실이 0.042 → 0.010으로 크게 줄었지만 PSNR은 +0.01 dB, SSIM은 오히려 0.620 → 0.602로 조금 떨어졌다. 교사를 학습 데이터와 같은 620장으로 학습해서, 학습 crop에서는 교사 출력이 정답과 비슷해 새 정보가 적었을 가능성이 있다(가설, 확인 전).
4. 같은 조건에서 **모델 구조를 바꾼 Max+는 Max보다 +3.6 dB**였다. 이번 실험 범위에서는 증류보다 구조 차이가 훨씬 컸다.

## 학습 시간 (Colab T4, 로그 합계)

| 실행 | 시간 |
|---|---|
| 일반 학습 Mini / Max / Max+ | 26 / 27 / 31분 |
| 증류, 교사 Max+: Mini / Max | 26 / 31분 |
| 증류, 교사 Retinexformer: Mini / Max / Max+ | 51 / 57 / 56분 (교사 계산으로 약 25분 추가) |
| Retinexformer 교사 학습 | 30000회 약 12.5시간 (18000회 이후 다른 계정에서 이어서) |

## 다음 단계 (슬라이드 하단)

- 크기별 최종 모델: 미리 정한 규칙(검증 PSNR 최대)대로 고르면 Mini* = 일반 학습(10.554), Max* = Max+ 교사 증류(13.541), Max+* = Retinexformer 교사 증류(17.134)다. 차이가 0.01 dB 수준이라 사실상 같은 품질이며, 선택기는 이 세 모델로 진행한다.
- 사진별 모델 선택: Mini가 Max+보다 나은 사진이 69장 중 9장 → 입력 밝기로 구분되는지 C와 확인
- 여유가 있으면 β 0.1 / 1.0, seed 추가

## 주의 (발표 때 말할 것)

- seed 1개, β 1개 결과다. "증류는 효과가 없다"가 아니라 **"이 모델·데이터·조건에서는 차이가 없었다"**로 말한다.
- 시험 100장은 아직 쓰지 않았다. 모든 수치는 검증 69장 기준이다.
