# 7장 초안 — 증류 예비실험과 진행 상황 (D)

> 2026-10-26 기준. Retinexformer 교사 증류 결과가 화요일 낮 전에 나오면 표에 한 줄씩 추가한다.

## 슬라이드 제목

**Max+를 교사로 한 증류: 같은 조건에서 차이 없음**

## 실험 조건 (한 줄 박스)

LOL-v2-real 학습 620장 / 검증 69장 · random 180×180 crop · batch 40 · 120 epoch · seed 42 · Colab T4
학생은 일반 학습과 **같은 initial.pt**에서 시작하고 설정도 같다(증류 항만 추가). 교사는 Max+ 일반 학습 best(17.13 dB)로 고정, 같은 crop을 교사·학생에 넣는다.
손실 = 기존 손실 + 0.3 × SmoothL1(학생 출력, 교사 출력)

## 관찰 (말로 설명할 내용)

1. **증류 효과가 없었다.** 평균 차이 ±0.01 dB이고, 사진별로도 증류가 나은 사진과 못한 사진이 반반이다.
2. **Mini·Max는 4~7 epoch에서 최고점을 찍고 그 뒤로 오르지 않는다.** 증류 손실도 3 epoch 이후 약 0.041(Mini)에서 더 줄지 않는다. 학생이 교사 출력을 따라갈 표현력이 부족한 것으로 보인다(가설, 확인 전).
3. **같은 조건에서 원본 해상도 보정망을 붙인 Max+는 +3.6 dB 올랐다.** 학습 신호를 바꾸는 것보다 모델 구조 차이가 더 컸다.

## 학습 시간 (Colab T4, 로그 합계)

| 실행 | 시간 |
|---|---|
| 일반 학습 Mini / Max / Max+ | 26 / 27 / 31분 |
| 증류 Mini / Max (교사 Max+ 추론 포함) | 26 / 31분 |
| Retinexformer 교사 학습 | 1000회당 약 25분, 30000회 중 18000회(약 7.6시간) 진행 |

## 진행 중 · 다음 단계 (슬라이드 하단)

- 진행 중: 더 강한 교사 Retinexformer(검증 21.99 dB, 9000회 시점 고정본)로 Max+ → Max → Mini 증류
- 다음: β 0.1 / 1.0 비교, seed 추가, 크기별 최고 모델 선발 → 사진 밝기 기반 모델 선택

## 주의 (발표 때 말할 것)

- seed 1개, β 1개 결과다. "증류는 효과가 없다"가 아니라 **"이 조건에서는 차이가 없었다"**로 말한다.
- 시험 100장은 아직 쓰지 않았다. 모든 수치는 검증 69장 기준이다.
