# 측정 규약 (화질·시간·메모리)

모든 방법은 아래 조건을 고정한 뒤 비교한다. 바꿀 경우 모든 방법을 다시 측정한다.

## 화질 (`scripts/evaluation.py`)

- RGB float32, [0, 1], 원본 해상도(600×400), 예측값만 [0, 1]로 clamp
- 이미지별 PSNR·SSIM(고정된 원 구현 함수)·LPIPS(AlexNet, 입력을 [-1, 1]로 변환) → 산술평균
- 밝기 맞춤(GT mean)·테두리 제거·8bit 양자화 후 채점은 하지 않는다. 외부 논문의 “GT mean” 수치와 직접 비교하지 않는다.
- 학습 중 checkpoint 선택: 검증 PSNR 평균 최대(동점이면 이른 epoch). 검증 중에는 속도를 위해 LPIPS를 생략한다.
- 시험 분할은 `allow_test=True`를 명시해야만 평가된다. 설정을 모두 고정한 뒤 한 번만 쓴다.
- “크게 품질이 저하된 사진” 기준은 미정. 이미지별 점수를 모두 저장해 나중에 계산한다.

## 시간·메모리 (`scripts/benchmark_cpu.py`)

| 항목 | 고정값 |
|---|---|
| 기기 | 측정용 노트북 1대: Apple M5 (10코어) MacBook Pro |
| 입력 | 600×400 RGB 저조도 PNG 1장, batch 1 |
| 정밀도 | FP32 |
| 스레드 | `torch.set_num_threads(1)`, interop 1 (기본). 필요하면 4스레드를 추가 보고 |
| 반복 | warm-up 10회, 측정 100회 |
| 통계 | 평균·중앙값·p95(95백분위)·최솟값 |
| 실행 조건 | 다른 학습·무거운 프로그램을 끈 상태, 전원 연결 |

시간 범위 두 가지를 구분해 보고한다.

- **model**: 메모리에 올라간 입력 텐서로 forward 1회 (출력 3개 모두 계산)
- **end_to_end**: PNG 디코드 → 텐서 변환 → forward → clamp → uint8 배열. 디스크 저장·화면 표시는 제외
- 사진별 모델 선택 시스템은 end_to_end에 **사진 상태 계산과 선택 과정**을 포함한다. 모델 단독 시간만으로 시스템 속도를 주장하지 않는다.

메모리는 모델마다 새 프로세스를 띄워 프로세스 최대 RSS를 잰다(PyTorch 런타임 포함). 선택 시스템은 세 모델이 동시에 메모리에 올라가므로 그 상태로 따로 측정한다.

학습 비용은 `runs/*/log.csv`의 epoch별 학습 시간(`train_seconds`)과 교사 준비 시간을 합산한다. 학습 장비가 달라지면 장비를 함께 기록한다.
